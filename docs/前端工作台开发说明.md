# Vue 前端工作台

## 技术栈

- Vue 3 + TypeScript + Vite
- `lucide-vue-next` 图标
- 原生 `fetch` 调用 FastAPI，Vite 开发代理转发 `/api` 和 `/health`
- 纯 CSS 设计系统，避免绑定复杂 UI 框架，便于学习布局和交互实现

## 当前页面

1. **问答工作台**：提交问题、调用 `/api/v1/qa`、展示回答、引用证据和检索轨迹。
2. **知识库**：调用 `GET /api/v1/knowledge` 展示 PostgreSQL 中的文档、版本、Chunk、审核和索引状态；支持浏览器上传 Markdown/TXT/PDF，也可选择预置资料；审核处理版本、确认 Embedding 预算后构建草稿索引，并在完整性校验后激活。Markdown/TXT 上传后自动进入轻量后台处理，PDF 仍需明确确认 MinerU 调用预算。
3. **评测记录**：读取 `evals/results` 中的真实检索/问答联调报告，支持按类型筛选、查看单次运行详情和调用记录；审核通过离线评测集后显示真实 Recall@5、Precision@5 和 MRR。

## 运行方式

```powershell
Set-Location frontend
corepack prepare pnpm@10.12.4 --activate
pnpm install
pnpm dev
```

浏览器打开 `http://127.0.0.1:5173`。Vite 会将 `/api` 和 `/health` 请求代理到 `http://127.0.0.1:8010`。因此需要另开终端启动后端：

```powershell
Set-Location ..
.\.venv\Scripts\python.exe -X utf8 -m multimodal_rag.cli serve
```

如果后端未启动，页面会标记为“演示模式”，保留示例回答和证据，方便先检查页面布局；提交问题时会提示连接失败，不会伪装成真实回答。知识库只读接口失败时保留示例行，不会把示例状态当成真实入库结果。

## 上传边界

- 客户端只上传文件内容和显示元数据，不能提交服务器本地路径。
- 后端限制扩展名、大小、UTF-8 编码或 PDF 签名，并将原文保存到内容寻址目录。
- 运行时上传清单与版本控制中的基准清单分离，默认不提交 Git。
- 同一知识库中的同名文件使用稳定文档编号；内容变化会产生新的原文和文档版本。
- PDF 外部解析不会在后台静默触发，必须由使用者确认 MinerU 请求预算。

## 当前限制

当前已完成本机依赖安装、前端构建和浏览器联调。评测页可读取真实报告，并在详情面板展示回答、引用、检索统计与外部调用记录；知识库页已接入浏览器上传、预置资料选择、持久化入库任务、人工质量审核以及索引构建和激活。当前不提供身份认证和公开网络部署，也没有实现文档下线入口；服务仅监听本机地址。
