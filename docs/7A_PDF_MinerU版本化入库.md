# 阶段 7A：PDF 与 MinerU 版本化入库

## 阶段目标与当前结论

v1.0.0 只把 Markdown/TXT 与关联图片接入了正式入库 Worker；MinerU 当时只用于受控样例的接口和解析质量验证。本阶段将已验证的 MinerU 能力接入正式版本化入库主线，但不放开任意文件路径、无预算调用或解析后自动上线。

当前已完成代码、数据库迁移、前端交互、离线回归和真实 MinerU 端到端验收。两页样例已完成解析、人工审核、增量索引、激活和图文问答验证。

## 正式处理流程

```text
白名单 PDF
  → 路径、格式、大小、SHA-256、页数与加密状态校验
  → PostgreSQL 创建可恢复入库任务
  → 明确确认 MinerU 请求预算
  → 申请签名上传地址并上传 PDF
  → 只持久化 batch_id，任务回到 pending
  → 用户显式触发轮询，未完成时不重复提交
  → 完成后安全下载并检查 ZIP 结构
  → 归一化为 Element，保留 PDF 物理页码、标题路径和图片引用
  → 结构感知切分并持久化 Chunk
  → 质量状态进入人工审核队列
  → 审核通过后才允许构建、激活新索引
```

提交/上传、轮询和下载被拆成可恢复阶段。签名 URL 仅存在于当前进程内存；PostgreSQL 只保存可审计的 batch_id、处理版本及产物哈希。服务中断后可继续轮询原任务，不会默认重复提交 PDF。

## 数据与产物设计

- `documents` 与 `document_versions` 保存 PDF 身份、内容哈希和原文版本。
- `ingestion_jobs.external_batch_id` 保存 MinerU 任务编号，不保存签名 URL。
- `processing_versions` 记录 MinerU 模型、归一化器、切分配置和质量状态。
- `elements` 保存标题、正文、表格、代码、图片以及原 PDF 页码。
- `chunks` 是参与 Dense/BM25 检索的最终单元。
- 新增 `parser_artifacts` 表记录解析包 SHA-256、本地产物路径、归一化器版本和图片数量。
- 解析 ZIP、归一化 JSON 和图片保存在 `data/derived/mineru_*` 下，默认不提交 Git。

## 安全和费用门禁

1. API 客户端只能传 `document_id`，源文必须在 `data/manifests` 白名单中。
2. PDF 路径必须位于 `data/raw`，格式签名、哈希、大小和页数均在提交前复核。
3. 默认上限为 20 MiB 和 200 页，加密 PDF 直接拒绝。
4. 网页必须勾选“我确认调用 MinerU”并设置 2～8 次 HTTP 请求预算。
5. POST/PUT 不自动重试；GET 只允许受限重试。每次网页操作最多推进一个解析阶段。
6. ZIP 不调用 `extractall`，会拒绝路径穿越、加密成员、重名文件、缺失结构和超限解压体积。
7. 解析成功不等于发布；PDF 仍必须通过人工质量审核和索引激活门禁。

## 本轮验证

- PostgreSQL 迁移 `009_parser_artifacts.sql` 已应用，数据库只读检查通过。
- 默认白名单新增一份 715,091 字节、2 页的公开 PDF 样例，本地哈希和页数校验通过。
- 后端 244 项测试通过，包含 PDF 白名单、页数限制、归一化、图片落盘、预算门禁、首次提交/上传、可恢复轮询、增量索引模式和 PDF 表格截图定位回归。
- Vue TypeScript 检查和 Vite 生产构建通过。
- 真实 MinerU 首轮提交和上传使用 2 次请求，轮询和结果下载使用 2 次请求；产出 35 个 Element，其中 30 个可索引、5 个页码/页脚/空元素被排除，最终形成 8 个 Chunk 和 4 张本地图片。
- 唯一质量警告为空表格残片。逐页核对原 PDF、解析文本与 4 张图片后，该版本由人工审核为 `approved`。
- 增量索引复用 1,078 个活动向量，只为新增 8 个 Chunk 调用一次 Embedding；新索引包含 70 个已审核处理版本，Chunk、向量和关键词条目均为 1,086，并已通过激活门禁。
- 首次真实图文问答发现 MinerU 将两张 QPS 截图识别成带图片资源的 `table`，旧定位规则只接受 `kind=image`，因而误选了 gRPC 图。修复后改为以已校验 `image_ref` 作为视觉证据契约，并结合图片前一段说明区分默认配置与调整后配置；同题重跑后正确定位默认 QPS 图，回答 `query OK Max=21.13 K`、`query Error Max=0`，同时给出文字和图片引用。

## 后续可选增强

当前样例已经验证完整工程链路，但仅有一份两页 PDF，不能代表任意复杂版式。后续可增加含跨页表格、扫描页、公式和多栏排版的 PDF 回归集，并继续沿用“解析质量人工审核 + 检索 Gold + 图文问答 Gold”的分层评测方式；这些属于覆盖面增强，不阻塞本阶段竣工。
