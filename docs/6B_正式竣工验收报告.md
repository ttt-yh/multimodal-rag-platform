验收脚本为 `scripts/verify_stage6b_web.py`，生成的本机报告和截图位于 `evals/results/stage6b/`。评测结果目录默认被 Git 忽略。

## 验收发现并修复的问题

首次端到端验收发现知识库页面请求：

```text
GET /api/v1/review-queue?state=all&limit=200&offset=0
```

后端 OpenAPI 将 `limit` 限制为最大 100，因此页面返回 HTTP 422。单元测试和 TypeScript 构建无法发现前后端运行时参数不一致。前端已改为 `limit=100`，重新执行完整浏览器验收后 HTTP 错误清零。

另对交互做了收口：问答页“添加资料”已连接正式导入窗口，“刷新评测”和“复制回答”已实现；没有后端支持的单工作区切换、工作区设置、帮助入口、会话保存和自定义证据排序被移除或明确禁用。
