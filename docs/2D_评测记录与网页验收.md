# 阶段2D：评测记录详情与网页验收

## 目标

在阶段2C把评测列表接入真实报告目录后，本阶段补充单次运行的可复核详情，并完成网页端到端验收。详情读取已有 JSON 报告，不触发新的模型调用。

## 当前实现

- `GET /api/v1/evaluations` 返回检索/问答联调列表和汇总调用次数。
- `GET /api/v1/evaluations/{run_id}` 返回单次报告的回答、引用、检索统计和供应商调用记录。
- Vue 评测页支持按“检索联调/问答联调”筛选，点击“详情”打开报告面板。
- 页面明确区分“联调报告”和“离线质量指标”。评测集未审核时不显示指标；审核通过并生成报告后，只显示本地计算得到的真实 Recall、Precision 和 MRR。

## 验收命令

